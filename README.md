# Airbnb Clone

A full-stack Airbnb-inspired web application built while learning backend development.

## Features

- User Authentication (Signup/Login)
- Session Management
- MVC Architecture
- CRUD Operations for Listings
- Reviews and Ratings
- Server-Side Validation
- Flash Messages
- Responsive UI
- MongoDB Database Integration

## Tech Stack

### Frontend
- HTML
- CSS
- JavaScript
- Bootstrap
- EJS

### Backend
- Node.js
- Express.js

### Database
- MongoDB
- Mongoose

## Project Structure

text
Airbnb-Clone/

## Installation

bash
git clone <repository-url>
cd airbnb-clone
npm install
npm start
